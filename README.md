## 🏢 Overview

**ANIL KUMAR MANISH KUMAR TILES SHOWROOM** is a modern, high-performance static web application built to serve homeowners, interior architects, civil contractors, and commercial builders. 

The website functions as a clean, digital product catalog and instant lead generation channel—allowing visitors to browse collections, verify authorized partner brands, get turn-by-turn showroom navigation, and instantly inquire over WhatsApp and direct phone calls without complex forms or database delays.

---

## ✨ Key Features

- **⚡ Blazing Fast & Lightweight**: 100% static frontend architecture with zero heavy dependencies or backend overhead.
- **📱 Responsive & Mobile-Optimized**: Fluid typography and adaptive grid systems that deliver a flawless experience across smartphones, tablets, laptops, and 4K displays.
- **💬 Direct WhatsApp Inquiries**: Dynamic product cards pre-populate WhatsApp messages with specific category inquiries (e.g., *"Hello, I am interested in Floor Tiles"*).
- **🗺️ Interactive Google Maps Integration**: Embedded map and direct GPS directions pointing straight to the showroom under the Jatauli Mandi Flyover in Gurugram.
- **🖼️ Curated Visual Galleries**: High-resolution showcase spaces covering living rooms, modern bathrooms, kitchens, and outdoor patio designs.
- **🤝 Brand Partner Showcase**: Interactive badges for premium manufacturer brands including Mehak, Indigo Paints, Kajaria, Jaquar, APL Apollo, Astral Pipes, Astral Water Tanks, Kerovit, Astral Bathware, Coats, Sakarni Tile Adhesive, Cravo, Kamdhenu Paints, and Sakarni.
- **📞 Multi-Channel Contact Hub**: One-tap phone dialing, instant WhatsApp chat floating action button (FAB), and email triggers.
- **🌐 Accessible & SEO-Ready**: Semantic HTML5 markup, meta descriptions, descriptive image alt text, and FontAwesome icons.

## 🚀 Quick Start & Local Setup

Because the application is built entirely with vanilla web technologies, no build tools, Node runtime, or compilation steps are strictly required.

### Option 1: Run with Vite Dev Server (Recommended)
```bash
npm install
npm run dev
```
Then open `http://localhost:5173` in your browser.

### Option 2: Open Directly in Browser
Simply double-click or open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### Option 3: Run with a Local Static Server

Using **Node.js (`npx serve`)**:
```bash
npx serve .
```

Using **Python 3**:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

Using **VS Code Live Server**:
1. Install the [Live Server Extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).
2. Right-click on `index.html` and select **"Open with Live Server"**.

## ⚙️ Configuration & Customization

All showroom metadata and dynamic content can be managed directly in `data.js`:

- **Update Contacts & Social Profiles**:
  Edit the `showroomConfig.contacts` and `showroomConfig.links` objects:
  ```javascript
  const showroomConfig = {
    contacts: {
      primaryPhone: "9350444783",
      secondaryPhone: "9671390896",
      whatsappNumber: "919350444783",
      email: "mannuchauhan13@gmail.com",
      address: "Jatauli Mandi, Under Fly Over",
      cityState: "Gurugram, Haryana, India"
    },
    links: {
      instagram: "https://www.instagram.com/anilkumarmanishkumar.3720/",
      facebook: "https://www.facebook.com/share/1EkNHfq69N/",
      youtube: "https://youtube.com/@anilkumarmanishkumar533"
    }
  };
  ```

- **Add or Modify Products**:
  Add items to the `productCategories` array in `data.js` to automatically generate new cards with customized WhatsApp inquiry triggers.

- **Add or Reorder Brands**:
  Update the `showroomBrands` array in `data.js` to showcase new brand partners.

- **Customize Colors**:
  Adjust CSS custom properties inside `:root` in `styles.css`.
